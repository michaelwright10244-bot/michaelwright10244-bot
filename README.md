## 🧑‍💻 About Me

> *我是谁不重要，重要的是这个 commit 能不能过 CI。*

- 🔭 **在做什么**：AI 提示词工程、全栈开发，把零散想法打造成真正能用的产品
- 🎯 **核心领域**：Prompt Engineering · AI 交互系统 · 前端(React/Vite) · 后端(FastAPI) · Three.js
- 💡 **产品理念**：让复杂的事情变简单，让简单的事情变优雅
- 🌱 **持续探索**：3D 可视化、媒体处理工作台、AI 辅助生产力工具
- 🎮 **代码哲学**：
  - 不会写 0 个 bug，但会写一堆能 work 的 bug 🐛
  - 信奉「它能跑，但我不知道为什么」教派 🙏
  - 擅长 push 完代码然后假装那是 AI 写的 🤖
